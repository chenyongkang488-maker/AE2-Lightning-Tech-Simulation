# Output interface color edit

Source: `overloaded_interface.png`, AE2 Lightning Tech contributors, CC BY-NC-SA 3.0.
Color adaptation: qiqi / Lightning Tech: Simulation, same asset license.

The built-in image editing tool produced `pink-white-blue-edit.png` from the
reference. Its output was sampled to a 16×16, nearest-pixel runtime sprite at
`src/main/resources/assets/overload_sim/textures/block/overload_output_interface.png`.
The editable Blockbench project embeds that runtime sprite. No arrow overlay.

Prompt: Preserve the original concentric-square Minecraft interface face;
change the burgundy/red frame to soft pastel pink, gray-white case to bright
pearl white with pale lavender-gray shadows, and blue center to ice/light sky
blue. Flat front-on square tile, pixel art, no arrows, glyphs, extra shapes,
perspective, surrounding scene or antialiasing.
