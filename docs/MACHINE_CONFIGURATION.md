# 闪电科技：模拟配置

从 **主菜单 → 模组 → 闪电科技：模拟 → 配置** 打开配置页。界面使用 NeoForge 自带的配置编辑器，无需安装额外的 GUI 模组。中文游戏语言显示中文分类、参数名称和说明。

配置页按文件显示三个入口：

| 界面入口 | 配置文件 | 内容 |
| --- | --- | --- |
| 模拟与工具设置 | `config/overload_sim-common.toml` | 模拟升级限制、自动输出间隔、ME 网络 FE 提取和共振线圈参数 |
| 激光消耗与爆炸设置 | `config/overload_sim-laser.toml` | 激光批次能耗、伤害倍率、接收器爆炸开关和破坏预算 |
| 机器数值与容量设置 | `config/overload_sim-machines.toml` | 普通模拟仓、多方块模拟室、共振线圈、特斯拉超限水晶配方、强能工作站、激光网络、坍缩核心、粒子约束器和约束器爆炸 |

这些文件保留内部名称 `overload_sim`，与项目公开名称“闪电科技：模拟”对应。

## 编辑、保存和恢复默认

将鼠标移到参数上可查看用途、单位和允许范围。范围较小的整数显示为滑块；较大的整数、长整数和小数显示为输入框。布尔开关使用“开／关”按钮。

输入框中的红色文字表示当前输入无效，该输入不会替换上一有效值。离开页面时，“完成”和 Esc 都会保存有效修改；Esc 不会丢弃修改。例如，将某项从有效值改为超出范围的红色值后退出，保存的是此前的有效值。

“取消”按钮是 NeoForge 的撤销操作，用于撤销当前页面的修改；它不是退出且不保存。“重置”将当前分类中的参数恢复为默认值，重置也可以撤销。重置不会递归修改其他分类。

## 生效时机和已有机器

“机器数值与容量设置”中的新参数均使用 NeoForge 的 `worldRestart` 机制。在世界中修改后，需要退出并重新进入世界，才会切换到新值；从主菜单修改后，在下次进入世界时生效。这适用于已有世界，也适用于新建世界，无需删除存档。“模拟与工具设置”和“激光消耗与爆炸设置”中的旧参数按说明实时生效。

降低容量上限会保留机器已有库存。超额部分仍可取出；库存降到新上限以下前，不再接受会增加该库存的输入。粒子约束器不会仅因配置降限而爆炸。降低升级或处理限制不会删除已安装的物品，只调整新上限允许的工作量。

配方时间、FE 消耗和闪电消耗的百分比以原配方为基准，默认 `100` 表示 100%。这些倍率用于新批次；已启动批次保留启动时的参数。特斯拉超限水晶配方的产出也在批次启动时确定。

两个激光阈值的比较方式不同：强能工作站的 `workstation.laserThreshold` 要求输入能量**严格大于**阈值；坍缩核心的 `core.activationThreshold` 要求输入能量**达到**阈值。两者的单位都是每 20 tick 激光批次的 FE，默认阈值均为 `1000000000`。

爆炸开关仍在 `overload_sim-laser.toml` 的 `explosionEnabled` 中，默认开启。关闭后，约束器爆炸的方块破坏、实体伤害、声音和动画都会禁用。球形半径使用 `overload_sim-machines.toml` 的 `explosion.radius`，默认 12 格。旧字段 `explosionVerticalRadius` 仅保留兼容，当前已忽略。

激光 `laser.maxBeamFe` 限制每 20 tick 批次的光束能量，默认 `1000000000000000` FE，即 1P FE。源头超过此上限时不发射，也不扣费；后续矩阵处理后超限时，不扣该矩阵的费用，但上游已经发射的费用仍正常结算。发射器每批消耗 `emitterFePerBatch` 的允许范围为 1–1P FE，实际发射仍受光束上限限制。

降低粒子容量后，如果旧存量仍超过新上限，约束器会显示“旧存量超过新粒子上限，请先消耗粒子”，暂不接收新粒子。先消耗旧存量至新上限以内，再继续接收。

## 多人服务器

这三个文件均为 COMMON 配置。多人服务器上的机器由服务端配置决定；修改客户端文件不会改变远程服务器的机器数值。服务器管理者应修改服务端 `config` 目录中的对应文件，并按参数的生效要求重启或重新载入世界。给整合包分发配置时，同时分发这三个文件。

配置范围是闪电科技：模拟自己的机器及其与前置模组的交互参数。AE2 Lightning Tech 和 Thunderbolt 是独立前置，它们原有机器的通用属性由各自配置控制。
