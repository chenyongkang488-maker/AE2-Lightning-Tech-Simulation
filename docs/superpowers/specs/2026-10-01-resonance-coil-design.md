# 谐振雷鸣线圈

目标：给模拟水晶绑定怪物提供可控落雷工具，同时通过工作站模块成为电流驱动的通用工具。目标 MC 1.21.1 / NeoForge 21.1.252；固定 AE2LT 2.1.0 和 AE2 19.2.17。

## 操作与模块

- 工具名称暂定“谐振雷鸣线圈”，需要闪电科技 `ultimate_overload_core` 才能使用。放进原生过载装备工作站自动绑定该工作站的 AE 网络。
- 短按右键，在松开时服务器重新射线检测目标：实体优先于其后方的方块，最大 32 格，不能穿墙。按住右键至少 30 tick（1.5 秒）后松开，落雷于自己。一次松开只产生一道雷，冷却 10 tick；无目标不扣费。
- 默认每次严格扣 10 HV，人工雷；极高压模块打开后严格扣 10 EHV，使用 AE2LT 的自然雷标记，支持自然雷仪式和收集器。不会用另一种电压替代。
- T1/T2/T3 使用现有能量模块，同苍穹能量容量，10M/1B/5B/20B FE；一件工具仅装一个能量模块，卸载容量减少时钳制缓存。不要求能量模块才能召雷，召雷仅付指定闪电。
- 拟态模块：下界合金采集等级，镐/斧/锹/锄/剑/剪刀能力、电流挖掘特效，剑的伤害与速度。潜行右键土地执行锹或锄的用途，普通右键保留召雷。
- 四个扩展均每种最多 1 件，安装时检查拟态前置；仍有扩展时拒绝拆除拟态。终极破坏允许采集所有等级并打破硬度 -1 的方块（含基岩、苍穹转化核心），仍尊重服务器权限及方块破坏取消事件。
- 效率默认打开 10 级，可以关闭及调整 0–10；时运默认 5 级，可调整 0–5；精准默认打开，可关闭，开启时覆盖时运效果。实际掉落上下文使用动态附魔，不只显示文字。
- 使用现有 G 配置键，在手持工具时优先打开专用配置界面；服务器校验持有位置、菜单 id、模块依赖、等级上下界。卸下模块立即关闭效果；原生苍穹/电磁炮配置保持有效。
- 挖掘和近战默认每次消耗 200 FE，可配置；工作站和手持工具支持 AE FE 换算充电、外部 FE item capability。没 FE 不能采集或近战；召雷只扣指定闪电，不扣 FE。没有核心时全部工具功能失效。

## 实现边界

使用独立 Data Components 保存核心、模块、配置与 long FE。只为本工具在 `DeviceWorkbenchAdapters.get(ItemStack)` 注入专用适配器，不覆盖上游按 DeviceKind 的注册表；目前上游没有可拓展设备枚举，本工具借 `RAILGUN` 标记通过工作站物品槽，其他行为全部按具体物品分派。工作站模块与核心原生 UI、安装延迟、卸载和网络绑定沿用上游。

public API `CoilModules` 提供安装/卸载/查询，`CoilSettings` 不可变配置，`CoilLightning` 支持服务器有效目标/扣费/生成；配置允许整合包调整范围、时间、冷却、FE 成本和充电速度。默认配方为数据包 JSON。

## 模型

Blockbench Java item 三维模型：八边形粉白金属线圈头横置于 XZ 平面，悬浮在短柄上方并留出明显间隙；粉色绕组、上下独立八帧动态闪电，深灰科技短柄、白色护手、粉色绝缘环、完美水晶徽章。绘图在 Blockbench 本地素材工坊完成；保存 `.bbmodel`、导出 Java item JSON、独立动态闪电贴图和预览 PNG。附加模块图标使用原创新贴图。

## 验证

真实工作站安装/卸载/网络绑定；序列化；缺核心/能量失效；模块依赖；HV/EHV 精确扣费与不足不扣；短按/蓄力、实体/方块遮挡；采矿等级与实际精准/时运掉落；基岩和苍穹核心、取消事件；非法配置。开发测试世界中查看模型、配置、工作站与挖掘动画。构建和全部 GameTests 通过后备份替换 PCL 测试实例 jar，并 Git 提交/标签。
