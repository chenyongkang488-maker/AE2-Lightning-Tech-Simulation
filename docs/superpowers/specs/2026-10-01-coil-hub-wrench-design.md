# 线圈原生设备界面与扳手模块

以用户六张截图为视觉与功能要求，MC 1.21.1 / NeoForge，AE2 19.2.17 / AE2LT 2.1.0；Mekanism 10.7.19.85 为可选运行依赖。

G 打开原生 DeviceHubMenu/DeviceHubScreen，四个苍穹装备标签保留，右上角原电磁炮标签按当前手持物品显示线圈或电磁炮，主手优先、有效副手回退。状态区、模块列表、滚动设置和原生复选框保留。只为线圈提供服务器状态与自有配置包；枪与护甲原功能不变。配置校验菜单 id、所选页、当前手持引用和模块依赖。

六个已有模块及新扳手模块由 Blockbench 在上游 overload_module_base.png 基础上绘制不同中心符号，保留原风格与素材许可。线圈两层八帧纹理改为四个方向的白芯粉色电弧汇入中心，颜色与模拟室渲染器一致。

扳手模块独立于拟态，仍需要过载核心；默认关闭。开启后禁用右键目标雷、蓄力自劈与已经开始的引雷释放。AE 扳手能力只在模块有效时启用；不把整个物品永久加入 wrench 标签。通用机械可选桥接调用原生配置器，实现八种模式：通用扳手、物品、流体、化学品、能量、热量、清空、旋转，保留权限、安全、管道和拆卸逻辑。无需另付闪电或 FE。未装 Mek 时 AE 扳手仍工作，界面说明 Mek 模式不可用。

旧五字段 CoilSettings 构造器与序列化保持兼容，新字段可省略；新扳手字段加入持久化与同步。后续模块前置和原有能耗规则不变。

验证原生界面共用标签、原枪/护甲不被改写；扳手开关/核心/卸载失效；引雷释放禁用；AE 旋转/拆卸保存物品，Mek 安全与侧面配置/管道/旋转/清空；无 Mek 的独立服务器；旧存档字段默认值。Blockbench 和实际客户端视觉检查后构建 alpha.7，备份替换 PCL jar，建立 Git 标签。
