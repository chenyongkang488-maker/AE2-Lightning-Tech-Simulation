# 平滑约束器与自动搭建审查

范围为 alpha.2 (`6b676649`) 之后的 alpha.3 变更，审查只读，未运行 Gradle 或修改工作区。

独立审查未发现未解决的生产逻辑、材料守恒、权限、菜单身份、结构适配或视觉所有权问题。AE 提取使用真实玩家和宿主来源，仅在宿主活动节点与参数网格一致时使用；退款保留物品组件，库存满时溢出返还给玩家。两套结构索引均参与空间预检。网格闭合、法线和环肋连续，客户端所有权由宿主 token 和区块可用性维护。

审查提示激光按钮可能同时显示 AE 与原版工具提示；实机复现后已统一到 AE `getTooltipMessage`。实机另发现玻璃被提前绘制导致背面肋条隐藏，已使用固定透明缓冲调整顺序，并兼容其它模组已注册相同缓冲的情形。

未纳入本轮的行为：球形碰撞/命中体积（保留原方块判定）；生产费用、带粒子约束器的爆炸规则、人工成型规则（既有行为）；违约 AE 后端返回不准确的提取数量（扩展必须遵守同步存储合同）。原生外观和界面尺寸由主代理实机验收。

统一验证：49 项单元测试、210 项 GameTest、版本和构建通过。原生检查与交付记录见 `docs/verification.md`。
