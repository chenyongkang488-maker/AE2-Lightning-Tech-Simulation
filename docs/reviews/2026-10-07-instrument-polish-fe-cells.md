# alpha.11 仪器反馈复查

复查范围：实产粒子与快照重播、四侧光口与动态施工模板、Applied Flux FE 结算、约束场、共用工作站建材、流体容器、强化量菜单与拖动控件。

已修复的实际问题：

- 空快照和时间回退后旧粒子重新出现：保留有界的发射时间历史，已观察到的飞行不会重播，未观察到的其它生产点仍可播放。
- 选用其它光口后原默认位置改为框架，施工投影过早返回，不能显示合法接口：先处理动态模板中的可选接口，再判断框架和光口。
- 堆叠容器在主物品栏满时进入盔甲/副手格：容器回收只使用玩家主物品栏的 36 格；没有空间时拒绝操作。
- FE 取出回调拆除机器，且原存储拒收退款时，退款晚于掉落序列化：世界级退款账本按设备身份暂存，原掉落恢复时只领取一次；内存卡不复制退款身份，普通零退款掉落保持可堆叠。
- 原生窗口实测滑条只能点击不能拖动：容器父界面消耗拖动事件，显式向已开始的滑条拖动转发并在松开时清理状态，物品拖放仍走原路径。
- 手持水桶右键成型框架，同时打开菜单和放水：客户端返回 PASS 后继续发送独立物品使用包。客户端仅消费已知成型菜单锚点的交互，服务端继续按真实归属验证；未成型、潜行及配置工具仍旁路。

退款拆机、重放历史和容器满栏都以失败回归复现后修复。退款身份、重复领取、内存卡隔离和任意自定义数据保留由游戏测试验证。滑条的实际拖动由窗口客户端验收，服务端范围和失效菜单由游戏测试验证。

独立只读复查确认退款修复与滑条事件转发没有剩余 P1/P2。最终测试组合、窗口截图和本地安装记录见 `docs/releases/0.2.0-alpha.11-verification.md`。
