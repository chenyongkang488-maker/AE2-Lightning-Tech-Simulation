## 资源与客户端

Blockbench 5.2.1 内加载本地素材插件、生成工程、绘画完美水晶高光，保存 PNG 与 bbmodel。四张 PNG 与 bbmodel 内嵌纹理的 SHA-256 一致。构建 JAR 包含四张贴图、17 个档案、39 个配方及 GuideME 页面，不包含前置模组代码。

开发客户端两次成功启动到主菜单，加载本模组资源；GuideME 扫描到了本模组页面和 item_ids。第一轮发现导航父页面不存在，已改为 AE2 的实际 machines 索引，第二轮无本模组导航错误。

前置 AE2LT 2.1.0 本身仍有 `extendedae:config` 配方条件未安装以及 `overloaded_power_supply` 资源缺失的日志；这些不是本附属模组新增的数据，服务器测试继续通过。此版固定依赖版本，尚不宣称支持其他 AE2LT 分支/版本。
