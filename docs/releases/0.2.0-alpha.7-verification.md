# 0.2.0-alpha.7 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation。

约束和聚焦矩阵显示当前激光 FE／次；离线 FE 缓冲供能同样显示真实脉冲，停机或过期后归零。成型外环分别使用粉色约束符文与双层青色聚焦镜圈，保留真实控制器及可选过载接口的开口。爆发矩阵向内部光束释放电弧，光束使用模拟室原有的流动像素球体材质，宽度与碰撞不变。

坍缩核心以 40 ticks 播放大球收缩再展开为蓝白球与紫橙电环的动画；只有首次接受有效工作或停机重新启动才播放音效。持续 20-tick 脉冲保留首次时间。上游快速停机/重启、结构失效和断能会重置下游视觉周期；正常每次重建光路不会重置。最终电环采用普通透明混合，避免白天天空把紫橙色叠加成白色。

验证：

- `matrix-red.log`：3 项新增纯逻辑/几何检查先因缺少实现失败；`matrix-green.log` 和最终构建的 69 项 JUnit 全部通过。
- `matrix-reviewed-tests.log`：224 项必需 GameTest 全部通过，包含实际完整演示光路的连续脉冲和迅速启停、菜单准确 FE／次与过期归零、核心存储以及取消事件不启动视觉。首次新增测试误把 1GFE 接受门槛当作 512GFE 粒子产出门槛，修正测试后通过。
- 修改最终客户端电环混合方式后，`matrix-native-final.log` 构建及 69 项 JUnit 再次通过；服务器逻辑未再次修改。
- 原生 Blockbench 绘制图集与 16 帧蓝白球体，既有 0～45 图块像素逐字节一致。约束、聚焦和球体附可编辑工程。`verify-laser-resources.py` 检查新模型、图层、UV、嵌入 PNG、动画和音效注册；`verify-multiblock-resources.py` 的原有 21 个工程、24 个 PNG 与 20 个模型通过。
- 原创音效为 44.1kHz 单声道、2 秒真实 Vorbis；客户端重启核心时出现“亚空间收缩并展开”字幕，持续脉冲不重复触发字幕。
