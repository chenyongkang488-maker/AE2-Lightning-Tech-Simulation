# 0.2.0-alpha.4 verification

Verified locally on 2026-10-05 with Java 21.0.12, Minecraft 1.21.1,
NeoForge 21.1.252 and AE2 19.2.17. The shared isolated worktree started from
`022b538519843df407a2aa2a96d30884be0fe78a` (alpha.3).

## Automated verification

- `gradle test runGameTestServer build verifyReleaseVersion -PmekTests -PcropTests -PfluxTests`
  passed in 40 seconds (`industrial-final-green.log`).
- 56 JUnit tests passed, with zero failures/errors. New tests cover orbit density,
  finite coordinates, bounds, segmented armour, plinth openings and precise
  clipping around functional blocks.
- All 221 required GameTests passed. Eleven new tests cover independently placed
  fixtures for all six orientations, new/legacy saved layouts, paid resource and
  timer retention, automatic construction and network snapshots.
- Before implementation, the new server and visual checks failed as expected;
  the local `industrial-*-red.log` and `receiver-pedestal-red.log` retain this evidence.
- `python scripts/verify-laser-resources.py` passed: 12 static block/item/state/loot
  sets, 138 workshop cubes, five embedded textures, native atlas parity, UVs,
  six facing variants, guides, and the 1462-face three-group formed workshop.
- `python scripts/verify-release.py --tag v0.2.0-alpha.4` passed. Runtime resources,
  metadata and licenses match the source. Optional test fixtures and dependencies
  are excluded from the release JAR.
- Independent read-only code review found no actionable P1/P2 issues.

## Native visual acceptance

Blockbench reloaded the updated art workshop plugin and exported the native
powder-white/pink atlas and its editable layer. The full formed constrainer
workshop was opened in Blockbench for mesh inspection.

The native Minecraft client loaded the existing developer world, then:

- Opened the new front controller and used its automatic build button. The
  7×9×7 structure formed with 195 newly placed blocks.
- Confirmed the merged two-layer base, front controller, segmented armour,
  cooling slots, recessed glass and visible construction detail.
- Observed an empty receiver without orbiting dots, then 32,000 and 125,000
  stored particles with increasing orbit density while production was paused.
  Successive screenshots showed movement and short trails within the shell.
- Inspected the same armour style on the existing matrix chain and emitter,
  and modest corner caps/vents on the original simulation chamber.
- Inspected standalone glass with a white/pink border and a standalone frame.
- Existing alpha.3 structures loaded and retained their original layout. Resource
  and paid-clock retention is verified by the automated save/load tests above.

The client saved its developer world and exited normally (Gradle exit 0).
The final renderer build includes a subsequent allocation reduction with
unchanged vertex arithmetic. No user world was modified during acceptance.

Unrelated upstream sprite-frame and recipe warnings remain in the developer log.
