# 0.2.0-alpha.10 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation。

新增强能工作站：7×7×7，封闭顶底和收光背壁、三面玻璃，大型像素收光面、四颗双尖粉色水晶和九位置物台。控制器包含九格材料和九格产物，每格上限 1,000,000，最高 1024 并行，两个连续有效 tick 完成一次。要求收到的单束激光严格大于 1G FE；激光替代原 FE / 闪电费用，仅消耗材料。

按用户澄清，继承运行时 `ae2lt:overload_processing` 过载处理工厂加工配方，包含整合包修改、删除、tag、组件和流体要求。专属类型 `overload_sim:high_energy_workstation` 与 Java 配方源扩展见 `docs/workstation-api.md`。全部资源交互在控制器上，支持手动和 shift 取放、六面输入/输出/双向、邻接弹出及 ME 产物导出；新接口默认关闭。保留自动搭建、施工投影和成型框架入口。

坍缩核心改为被动光学器件，只显示当前强度、核心余量和阈值；移除工具栏、自动搭建、投影、开关、玩家物品栏和网络状态，拒绝 AE / 过载网络绑定与 FE 能力。旧资源保留，旧关闭状态迁移为可接收。

激光与已成型发射面的真实光照由有归属、无碰撞的透明光照代理提供。仅替换空气，数量与维护工作有界；共享光源按最高值维持，停机/拆除回收，卸载不强制加载区块。

验证记录：

- `build/verification/alpha10-final-new.log`：87 项 JUnit、297 项必需 GameTest、构建和版本校验通过，退出 0。运行时 AE2 19.2.18、AE2LT 2.1.1、Thunderbolt 2.0.2。
- `build/verification/alpha10-final-old.log`：同一生产实现于 AE2 19.2.17、AE2LT 2.1.0、Thunderbolt 2.0.0 下 297 项必需 GameTest 通过，退出 0。
- 两组均为 Minecraft 1.21.1 / NeoForge 21.1.255，并启用 Mekanism、Mystical Agriculture、Applied Flux。兼容结论限于上述实测组合。
- 核心隔离、激光光照、导出时重入拆除、流体拒收/部分接收和唯一封装掉落均有先失败后通过的真实回归测试。配方、百万数量、重叠 Ingredient 分配、严格门槛、1024 并行、输出满、重载、组件/流体、四朝向、所有权和菜单快捷操作均在测试中覆盖。
- 外部激光来源关闭、拆除、卸载、阻挡和路由改变及时撤销收据；多束不足门槛的激光不能合并。复查记录见 `docs/reviews/2026-10-07-high-energy-workstation.md`。
- 最终客户端渲染修改后，`alpha10-native-render.log` 的单元测试和构建通过，窗口化客户端正常保存退出，Gradle 退出 0。此前两轮客户端也正常保存退出。

窗口化原生客户端为 854×480，guiScale 2，使用新版前置和三个可选模组。确认工作站形成、实际加工达到 1024 并行、产物正常保留、完整界面没有裁切，六面接口和两个导出选项默认关闭。玻璃外可以同时看到四颗双尖水晶与九位置物台。坍缩核心页面仅包含能量和阈值。夜间在激光旁 F3 读数为 `Client Light: 15 (15 sky, 11 block)`，其中方块光照为 11，确认存在真实方块光照。
