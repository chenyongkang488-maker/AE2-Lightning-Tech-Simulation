# 0.2.1-alpha.3：自动搭建后的 Sodium 渲染崩溃

来源：用户提供 `错误报告-2026-10-10_13.11.31.zip`，其中崩溃记录为
`crash-2026-10-10_13.11.20-client.txt`。运行附属版本 alpha.2，Sodium
0.8.13+mc1.21.1、Iris 1.8.14-beta.1；实例为 New Age Science and Technology。

## 已确认的原因

`latest.log` 在 13:11:15.739 显示「自动搭建完成，补放了 15 个方块」。
13:11:16.022 起多个区块网格线程报错。崩溃对象为 `overload_sim:laser_frame`，
位于 `allthemodium:mining` 的 `(-61,256,-284)`。

调用链是 `ReceiverShellModel.getModelData` → `ReceiverShellVisuals.hidden` →
`Sodium LevelSlice.getLightEngine()` → `UnsupportedOperationException`。
原实现用渲染视图的光照引擎作为外壳归属缓存的世界标识，Sodium 的
区块快照没有实现此调用。自动搭建已完成，随后的客户端框架网格重建
触发崩溃；日志没有证明某个光影包是直接原因。

alpha.3 将激光和强能工作站外壳缓存改按实际 `Level` 标识。新桥接按字段
类型、每个视图类只解析一次其捕获的世界，兼容原版 `RenderChunkRegion`
与本报告 `Sodium LevelSlice`，不依赖 Sodium 安装，也不调用视图光照引擎。
异步旧世界任务仍使用其自身捕获的世界，避免切换维度后串用外壳状态；
无法解包的其它视图保留普通方块模型。既有区块卸载清理及隐藏单元快照
保持原逻辑。

## 虚影未显示

原虚影在 AFTER_PARTICLES 阶段输出到 PARTICLES_TARGET。此路径依赖
粒子／光影的中间缓冲。修复将其改为 AFTER_LEVEL 与主画面目标，并
像原无线接口指引一样应用相机逆旋转；保留相机坐标差的双精度处理。
这是根据渲染代码调整的兼容路径，用户的具体光影环境仍需手测确认。

## 交付范围

2026-10-10 仅执行 `gradlew jar sourcesJar` 编译打包。沿用用户要求，未
运行自动测试、GameTest、发布／资源检查或客户端验收。

用户明确确认安装到 New Age Science and Technology。仅备份替换该实例
附属 JAR，保留前置、光影、配置及世界；未启动或修改存档。不自动替换
先前 OverloadSim-Test 实例。备份及哈希见 `0.2.1-alpha.3-install.json`。

手测：保留 Sodium/Iris 与现有光影进入世界，查看已搭建框架能否正常
渲染，再对未成型机器开启虚影并转动视角，最后尝试自动搭建。
