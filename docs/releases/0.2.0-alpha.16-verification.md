# 0.2.0-alpha.16 本地开发验收

闪电科技：模拟 / Lightning Tech: Simulation，基线 `63b49e416ba90f50fb8bb0abd62f8a2b222042e1`。

制造配方按用户的 `配方.txt` 添加。共 13 项：激光框架在过载处理工厂消耗 8 过载合金板、2 下界合金锭、2 铁块、4000 mB 熔岩、32 高压和 100k FE；通光玻璃在工作台用一框架和八石英玻璃；其它十一项使用闪电装配室。粒子约束器的材料歧义按用户确认采用 64 个 `ae2lt:firmament_alloy_ingot`。材料名称分别在 AE2LT 2.1.0/2.1.1、AE2 19.2.17/19.2.18 的原生资源中核对。独立脚本逐项核验数量、FE、电压、闪电数量和工作台排列，原有 18 项制造配方保持不变。

删除 `high_energy_workstation_frame`、`high_energy_workstation_glass`、`high_energy_workstation_receiver` 的物品、方块注册、资源及三个回收转换配方，结构仅使用共享激光部件。该删除遵循用户本轮明确要求；其余 ID、控制器物品/流体缓冲和保存格式保留。资产生成脚本不再重新生成旧部件或便宜的控制器工作台配方。

偏折矩阵先收集实际连通组件的同批有效输入，再守恒均分输出，整数余数也分配。真实工作站可接受两条 600M FE 输入合并后的 1.2G FE 光束，核心和普通矩阵也处理合并后的实际能量。支付、输出和粒子结算同批只执行一次；停止一个来源时保留其余贡献，最后一个来源停止才撤销租约。共享光段和粒子飞行只有一个显示宿主，迁移保持原发射 tick。单个偏折器总输入超过 1P FE 时停止该矩阵输出，不静默截断。扩展目标新增默认无操作 `refreshLease`，只刷新剩余强度，不重复执行材料或 FE 事务。

`config/overload_sim-laser.toml` 新增 `explosionEnabled = true`。设为 false 时停止爆炸破坏、实体伤害、音效、动画和待执行队列。开启时以约束器光学中心为圆心，使用半径 12 格的球体；方块中心和实体位置做精确球内判定。原生 `GENERIC_EXPLODE` 与 `EXPLOSION_EMITTER` 使用相同中心。逐 tick 有界扫描，不强制加载区块，保留不可破坏方块并遵循保护事件。旧 `explosionVerticalRadius` 为配置兼容保留，但不再改变范围。`BeforeExplosion` 保留旧构造器和 chunk 方法，新增块半径和光学中心字段。

模组公共名称按 AGENTS.md 保持“闪电科技：模拟” / “Lightning Tech: Simulation”，技术 ID、资源命名空间和包名仍为 `overload_sim` / `dev.overloadsim`，以兼容既有存档。仅本附属模组的 NeoForge 详情行显示本地化公共名称；其它模组仍由原生 ID 格式显示。
