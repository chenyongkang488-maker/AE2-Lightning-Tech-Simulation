# 0.2.1-alpha.6：输出接口交互与超限水晶 JEI

输出接口绑定路径原先只添加连接，重复连接只提示已连接。按用户本次要求，单次再次点击相同目标面改为删除当前源槽的这一条连接；其它槽、其它面均保留。Ctrl 批量继续只补充连接。沿用服务端手持工具、选槽、交互距离及权限检查，取消已有连接不依赖目标当前接收能力。删除后使用原有同步路径更新光线和目标列表。连接 API 的 addConnection 仍为仅添加。

方块补齐手持支持的升级卡右键插入，方块实体实现 AE2 IUpgradeableObject 以接入 Shift 右键原生插卡。卡种及数量继续由现有升级库存验证；普通右键只扣除实际插入数量，创造模式保留手中卡片。

超限水晶已有真实生产和特斯拉处理逻辑，但附属尚无 JEI 注册。新增可选 JEI 插件：强能工作站分类读取 WorkstationRecipes 的最终配方目录（继承加工厂配方、工作站独有配方及公共扩展源），显示完整物品数量、流体及激光门槛、周期和并行；不展示工作站实际未收取的原加工厂 FE／高压费用。超限水晶默认为256过载水晶产4个。特斯拉独立页面显示1超限水晶、坍缩矩阵催化要求、500000 FE、5有效 tick 和64极高压，数值读取模组配置。

两个机器均注册催化机器入口。工作站箭头打开工作站配方。JEI 只响应第一个重叠点击区域，因此特斯拉直接扩展前置原点击区域，合并原配方和超限水晶页面；兼容 Reborn 2.1.0 的单 RecipeType 和主项目2.1.1的 RecipeType 数组方法签名。JEI 是 compileOnly，不打包到附属、不作为必需前置。

保留已有 alpha.5 渲染优化。更新 G 指南、API 操作说明及已有连接 GameTest 的预期行为；按用户要求未运行测试或客户端验收，仅执行 jar sourcesJar 编译打包。安装到 New Age Science and Technology，备份及哈希记录见本目录安装 JSON。手测：二次点击取消，第三次点击恢复；同面其它槽和同槽其它面保留；普通／Shift右键插卡；超限水晶 R/U、工作站和特斯拉界面箭头能看到对应配方。运行时表现尚待用户确认。
