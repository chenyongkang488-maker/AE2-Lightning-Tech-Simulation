# 0.2.1-alpha.5：视野裁剪与固定顶点缓存

用户确认继续尝试保持外形的优化。本次集中处理客户端外壳／光束的视野裁剪和固定模型顶点缓存，保留 alpha.4 的光照采样缓存。

## 视野裁剪

直接把 `shouldRenderOffScreen` 改成 false 会让机器依赖控制器区块的可见性：外壳和长光束跨区块时，控制器不可见仍可能有部分模型在镜头内。核对当前 Sodium 0.8.13 的全局方块实体绘制入口后，保留成型机器的跨区块入口，在渲染器内部进行裁剪。

- 激光机器外壳和各段光束分别检查相机视锥；外壳不可见时不扫描外壳、不更新光照缓存、不生成外壳顶点。外壳和所有活动光束均不可见时提前返回。
- 保留仍在视野内的光束，即使其控制器和外壳位于镜头外。
- 强能工作站在其完整范围离开视野后提前返回。
- 外壳范围包括接收器底座、矩阵外圈、爆发弧线和坍缩核心的旋转／动画包络；光束范围沿用已包含宽度的分段边界。
- 通过可选的方法句柄读取当前 Iris `ShadowRenderingState.areShadowsCurrentlyBeingRendered()`，阴影阶段保持原有绘制行为，避免画面外机器不再投射阴影。桥接无法解析／调用时保守保留绘制；没有 Iris 时使用普通相机裁剪。

## 固定顶点缓存

新增 `PreparedMachineMesh`，预计算外壳固定顶点的局部坐标、朝向变换、法线和纹理坐标。保留原四边形、顶点顺序、浮点转换顺序、材质、光照、颜色及普通 `VertexConsumer` 提交路径，兼容已有 Iris 扩展。相机变换和动态光照仍在每帧应用。

激光机器在结构、朝向或中心变化时更换几何缓存；强能工作站复用固定模型缓存。资源重载后图集精灵身份变化，重新计算图集 UV。旋转晶体仍应用原动画变换，底座屏幕保留动画贴图。

没有修改模型或贴图资源，也未减少模型面数、粒子数量、动画、光束宽度或绘制距离。没有修改 AE 输出、机器生产或其它服务端逻辑。本次缓存固定顶点的计算结果，仍通过既有缓冲提交，没有引入独立 GPU 缓冲或额外渲染依赖。

## 交付

执行 `gradlew jar sourcesJar` 编译打包，沿用用户要求不运行自动测试或客户端验收。备份 alpha.4 并安装 alpha.5 到 New Age Science and Technology，Git 提交、标签与安装哈希记录在 `0.2.1-alpha.5-install.json`。

手测重点：同一机器区块转身后的流畅度；控制器离开镜头但光束、底座或机器边缘仍在画面时是否连续显示；光影开启时阴影是否保留；资源重载和切换维度后贴图与光照是否正常。实际性能改善与视觉表现尚待用户手测确认。
