# 0.2.1-alpha.7：前置版本统一与客户端包路径兼容

用户报告 `错误报告-2026-10-11_0.07.10.zip` 来自 New Age Science and Technology。首要故障是 NeoForge 依赖排序拒绝加载：本体为 Reborn 2.1.0-beta.6.alpha.1，低于附属要求的正式2.1.0；封包样板供应器1.2.2-beta要求本体至少2.1.2-beta、Thunderbolt至少2.0.3-beta，报告核心为2.0.0。报告末尾另有CustomSkinLoader的IFakeIResourceManager$V1缺类异常；该类实际存在于已安装Universal JAR的内嵌Common JAR，可能是依赖错误导致模组层未正常加载的后续问题，尚无客户端启动证据确认它是独立故障。

用户明确回复“都帮我更新到最新版”。按2026-10-11查询官方Modrinth发布接口的MC1.21.1／NeoForge结果：

- [AE2 Lightning Tech 2.1.2-beta2](https://modrinth.com/mod/ae2-lightning-tech/version/Hj7rsUUQ)，2026-10-09发布；要求Thunderbolt至少2.0.3-beta2。
- [Thunderbolt Core 2.0.3-beta2](https://modrinth.com/mod/thunderbolt-core/version/oyVnlG5A)，2026-10-09发布。
- [AE2LT Packaged Pattern Provider 1.2.2-beta](https://modrinth.com/mod/ae2lt-packaged-pattern-provider/version/gpNiszro)，2026-10-08发布；当前安装文件SHA256已经与官方发布文件一致，保留原文件。

下载文件对照官方SHA512，安装另记录SHA256。没有把旧Reborn alpha的版本号改成正式版，也没有绕开必需依赖范围。

进一步读取最新版JAR确认客户端类迁移：TextureToggleButton移至client.widgets，DeviceHubKeyMappings移至client.hub，Ae2ltRenderTypes和WirelessConnectorRenderer移至client.render。alpha.6会引用不存在的旧类，因此发布alpha.7客户端兼容补丁：按新旧包名缓存解析原生类；按钮委托原生按钮绘制、状态切换、回调及提示，保留原贴图；连接渲染Mixin以Pseudo多目标覆盖新旧类，普通前置选择仍保留原行为。继续针对旧2.1.0 API编译，保留旧接口入口与原支持范围。默认开发运行依赖改为当前配套beta2，旧版本可通过Gradle参数选择。

特斯拉、频率、连接工具、设备状态模型以及读取的其它关键声明与旧2.1.1一致。这是静态故障分析，不能视为游戏兼容实测。仅执行jar sourcesJar编译打包；按用户先前要求不执行单元测试、GameTest或客户端启动验收。前置、本附属旧JAR先备份到实例addon-backups，再安装配套更新；世界、其它模组和配置不修改。安装路径、旧文件、哈希和Git提交见同目录安装JSON。若启动仍报告CustomSkinLoader异常，需要依据新日志单独处理。
