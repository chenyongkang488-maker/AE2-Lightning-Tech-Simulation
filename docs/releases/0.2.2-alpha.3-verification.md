## 窗口发现与修复

alpha.2 中实际复现两项问题：

1. 三维结构在大窗口完全消失，在小窗口仅显示一角。原因是 Minecraft 1.21.1 的 `GuiGraphics.enableScissor` 使用绝对 GUI 坐标，不会应用 JEI 已平移的 pose。修复为先通过当前 pose 将预览矩形两角变换为绝对坐标，再启用裁剪。
2. 854×480、GUI 缩放 2 时，结构页底部控件超出窗口。修复为 144 高的布局，重新安排材料、总数、帮助和操作按钮；输入命中区域同步调整。

上述问题先在真实窗口观察到失败，再在修复版复验。独立代码复审直接核对了本地 Minecraft 裁剪实现及控件坐标，没有可确认的遗留问题。alpha.2 产物和历史验证记录保持原样，本轮修正版使用 alpha.3。

## 夹具与验证边界

本轮视觉夹具只存在于复制的测试存档。初始组合把偏折放在聚焦矩阵的采掘射程内，采掘按既有规则破坏光口；另一个发射器与球壳距离过近，触发既有间距限制。调整为独立上下光路和四条独立环矩阵光路后完成验收，没有为通过夹具而修改生产光路或结构规则。测试能源／极高压为有限预充。
