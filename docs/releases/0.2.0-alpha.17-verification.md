# 0.2.0-alpha.17 验证记录

主菜单 → 模组 → 闪电科技：模拟 → 配置使用 NeoForge 原生 `IConfigScreenFactory` / `ConfigurationScreen`。注册只位于 `Dist.CLIENT` 的 MOD 事件订阅类，保留技术 ID、三个 COMMON 文件、旧配置键及旧存档。新增 48 项运行参数按 9 类分组，默认数值保持 alpha.16 平衡；原有费用、升级、线圈参数和爆炸开关也有中英文名称、范围与说明。

新参数标记 WORLD 重启。真实 NeoForge 生命周期会在退出世界或停服时清理缓存，下一次进入世界采用已保存数值。测试覆盖 get/set 保留当前世界值及 `resetCaches(WORLD)` 后采用新值；测试内同步设置及还原后清缓存，不把测试覆盖状态留至下一 tick。
