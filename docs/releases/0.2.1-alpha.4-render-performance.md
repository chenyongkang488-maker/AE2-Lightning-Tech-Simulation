# 0.2.1-alpha.4：保持外观的光照采样优化

用户在 FTB 保持加载的机器区块内严重掉帧，离开机器的客户端加载范围后恢复流畅，关闭光影仍然卡顿。2026-10-10 对 alpha.3 运行实例做了两次短时 JFR 采样；第二次日志确认光影已关闭。

关闭光影的 20 秒采样中，渲染线程有 1010 个执行／原生方法样本，813 个包含 `LaserRenderer.render`（80.5%），533 个包含外壳光照采样路径（52.8%）。这些是有重叠的调用栈占比，不是 FPS 或整机 CPU 占比。主热点是外壳四角和中心采样时重复创建坐标、做世界坐标换算及哈希查询。采样还发现 Iris 的顶点注入；关闭光影包并没有卸载 Iris。

## 实现

- 新增 `PreparedSurfaceLighting`：为每个固定模型面预计算四角和中心的世界采样位置，以及原有的透明面外探位置。
- 每个采样方块每帧只读取一次光照／遮挡状态；固定位置、探针和模型面结果跨帧复用。光照或遮挡变化时重新求各面亮度，未变化时直接返回缓存值。
- 保持原有四角和中心取最大方块光／天空光的规则，以及 1/32、1/4、1/2、3/4、1 格的遮挡外探规则；不降低光照刷新频率。
- 激光机器外壳变化或朝向／中心变化时更换采样缓存；强能工作站朝向／中心变化时同样重建。世界使用弱引用，避免弱机器缓存反向保留世界。
- 保留所有模型面、顶点、贴图、渲染材质、动画、粒子、光束、绘制距离和视野裁剪规则。未修改服务端光路、AE 输出及生产逻辑。

第一轮另外捕获过输出接口返还来源的 AE 节点遍历／排序热点（121/531 服务端样本），第二轮未捕获。本次仅集中处理两轮都确认的客户端外壳光照热点。

## 交付范围

用户确认按方案实施，仅编译 `jar sourcesJar`，备份替换 New Age Science and Technology 中的附属 JAR。未运行自动测试、资源检查或客户端验收；实际性能改善幅度与外观由用户手动确认。构建和安装凭据见 `0.2.1-alpha.4-install.json`。

手测可在同一位置、视角和光影设置下比较流畅度，并检查接收器、偏折矩阵和强能工作站的外壳；放置／拆除灯、修改框架开口、卸载再加载及切换维度后观察亮度是否更新。
