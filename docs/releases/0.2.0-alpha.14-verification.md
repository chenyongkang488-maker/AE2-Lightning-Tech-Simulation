# 0.2.0-alpha.14 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation，基线 `849eb823e8f65282372c90b2ac828b31b939ea30`。

新增 `overload_sim:transcendent_crystal`（超限水晶），普通堆叠上限 64。强能工作站的专属数据包配方以 256 个本体过载水晶产出 4 个超限水晶，使用既有激光门槛、2 个有效 tick 和最多 1024 并行，仅消耗材料。完整最终配方目录中，四组各 64 个原料通过自动化接口投入可正确选择该配方；不足 256 个不加工，1024 并行精确消耗 262144 个并产出 4096 个。

水晶贴图从 AE2 Lightning Tech Reborn 2.1.0 的原生过载水晶改为淡蓝色，保留 16×256 的动画帧、各像素 alpha 和亮度、16 帧顺序及最后一帧的停留时长。模型显示方式保留原版。上游这三项素材在 2.1.0、2.1.1 的字节一致；生成器核对来源哈希，重复运行输出稳定。衍生素材继续采用 CC BY-NC-SA 3.0，出处和修改列入现有分层许可说明，不打包前置 JAR。

特斯拉线圈沿用本体网格 tick、五步 FE 充电、进度界面与网络输出。真实闪电坍缩矩阵是必需条件；每次仅消耗 1 个水晶和 500000 FE，产出 64 极高压，不抽取高压闪电。矩阵数量不放大此配方；缺矩阵、能量不足和输出空间不足暂停。已锁定的普通粉末加工不会把中途替换的水晶当作原耗材。只对新水晶调整配方判定，本体粉末制高压和高压转换极高压的成本、产出保持不变。

约束器通过现有 `particle_conversion` 数据规则接受新水晶，无需通用机械。参数与钚球、钋球一致：每件 100 个有效 tick、每 tick 消耗 1 粒子、产出 2048GFE；缺粒子或 FE 空间不足时暂停，存档保留已支付时间。
