# 0.2.0-alpha.6 像素反应堆验收

成型高能激光发射器改为阶梯式像素反应堆：粉白陶瓷外壳、八组矩形电容装甲、三层亮粉同心导光环及中央发光芯。所有基础几何顶点位于 1/16 格网格，固定 1868 个展示面（真实控制器开口裁剪后），最大坐标小于 2.85 格的既有渲染边界。

使用 Blockbench 的本地像素绘制工作坊导出图集；逐像素核对旧图集上部 128×80 区域保持一致。新资源为独立原创素材，复用水晶资源原有许可保持不变。`laser-emitter-reactor-formed.bbmodel` 包含五个原生可编辑分组，由同一 Java 网格导出，控制器与可选 AE 接口保留真实开口。

发光面同时绘制不透明底层和独立无方向光覆层；固定绘制缓冲防止切换 lightning 材质提前刷新，两层均写入深度，防止原光口玻璃覆盖亮粉核心。客户端发现原版 entity translucent emissive 着色器仍执行 `minecraft_mix_light`；核对本地 1.21.1 着色器源码后，改用原版 opaque beacon beam 材质保持原始亮粉像素颜色。未成型时保留普通建材外观。

5×5×5 模板、配方、FE 费用、存档 ID、激光方向和原有三格粗束不变；保持 alpha.5 的新旧前置兼容范围。
