# 0.2.0-alpha.12 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation，基线 `1c0d581`。

本轮完成五项反馈：成型结构内部禁止包括蝙蝠、友好动物在内的自然生成；强能工作站接收共用激光光口上的普通及未聚焦矩阵激光；工作站去除外部黑杆，改成整体外壳、连续玻璃、独特导线纹路、黄色小扳手控制器；四个真实过载水晶簇底部贴合收光内壁，通电时发射四束光到置物台；工作站 UI 增加分区边框和左右竖直带刻度流体槽，并以两个独立、默认关闭的相邻容器/AE 网络自动输出开关替代输出面设置。

水晶位置和输出配置范围的补充问题未收到回答，采用收光内壁、强能工作站范围。其它机器的方向配置保持原有功能。旧工作站输出方向字段不再限制管道或弹出；所有控制器面均只允许材料进入输入缓冲、产物从输出缓冲提取。仅自然生成被拦截，指令、刷怪蛋及已存在生物不被清除。原约束矩阵工作时的伤害行为保留。原单束最大强度、严格大于 1G FE、实际源 FE/EHV 费用、源停止后撤销租约、2 tick/1024 并行和材料守恒规则保留。
