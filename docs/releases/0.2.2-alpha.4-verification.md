## 实现与行为

新增实体底座升级“原初模块”，ID `overload_sim:simulation_primordial_module`。每座限一个，与熔炼互斥，支持效率、时运及过载。成功转换的矿物水晶以一块自然矿石为基础应用模拟室时运，每颗额外费用默认 2 高压；原初转换绕过普通掉落抽取。普通回退、生物、作物和树木沿用原行为。

解析顺序为数据包指定、十种原版固定表、材质矿石标签唯一有效候选。数据重载或 Java profile 的世界上下文变化会失效缓存。GUI 提供当前模式、已固定批次费用及回退诊断。已开始批次固定产物和费用，结构失效暂停；未开始批次配置变更后重新规划。结算仍在完成时扣费，保持既有 settlement version 2 语义。

新增配方：闪电装配室，模拟室框架×1＋精准采集附魔书×1 → 原初模块×1，100,000 FE＋32 极高压，消耗附魔书。更新中英文指南、API、制造配方文档，以及独立纹理、运行模型和可编辑 Blockbench 工程。

## 实际窗口验收（2026-10-22）

此前用户暂缓窗口检查；本轮用户要求“验收”，并明确回复“可以，现在交给你操作”。使用当前前置栈、JEI 19.44.0.403 与 AppliedFlux 的独立开发客户端，仅操作复制的 `alpha24-primordial-review` 存档。窗口内容 854×480、GUI 缩放 2、中文。客户端最后正常保存并关闭，未替换实例 JAR。

- 正常 4×4×4 模拟室组合原初、时运、效率 T3、过载模块，成型并持续运行。四颗水晶分别为铁、红石、小麦和夹具自定义未匹配矿物。
- 铁与红石直接产出自然矿石。红石产物悬停确认为“红石矿石”，应用一块基础产出与 ×2 时运；普通掉落多粒规则没有带入原初矿石数量。小麦保持普通产物，未匹配矿物产出普通圆石。
- 实际批次显示 `86t · ×2 · 原初`，费用 `4000 FE · 8 高压 · 4 极高压`，原初转换 2 颗、回退 1 颗，提示额外 2 高压不随时运增加；缺失矿石回退没有附加费。
- 单独的原初＋熔炼结构不成型，显示“原初模块与熔炼模块不能同时安装，请拆下其中一种”。两块原初结构不成型，显示“每座模拟室最多安装一个原初模块”。观察期间冲突结构没有产出，安装方块保留。
- JEI 按中文名称检索到独立模块图标，闪电装配室配方显示框架与附魔书、100k FE、32 极高压；书的悬停信息明确为精准采集。
- 原初模块在底座内显示独立青绿色晶体纹理，模块外形、顶面与侧面没有缺失贴图。游戏原生截图没有经过图像编辑。
- 保存退出、修正版重启及 `/reload` 后，正常模拟室仍成型并继续产出，模式和费用提示保持一致。精确的批次重启／暂停／防重复收费边界由下述 GameTest 覆盖，窗口观察不替代这些自动测试。
