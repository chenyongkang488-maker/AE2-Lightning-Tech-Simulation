# 0.2.0-alpha.9 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation。

实现用户七项反馈：连续粉色光束；中央双尖六棱水晶作为偏折交点；四个匹配三格光束的水平大光口；上下封闭；四面独立关闭/输入/输出且新设备默认全关；自动搭建下方的客户端施工投影；成型框架右键控制页面。保留 alpha.7 外环粉/青符文、模拟室光球和既有资源费用。

模拟室尺寸选择另保存到 `SelectedBuildSize`，查看投影后菜单重开及保存恢复保持 3～7 的选择。旧偏折结构保留资源和锚点，仅迁移水平光口；旧竖直控制器占用一个侧面时，该旧结构可用水平物理端口为三个，需四面时按新模板重建。

验证记录：

- `build/verification/alpha9-final-new.log`：78 项 JUnit、264 项必需 GameTest、构建及版本校验通过，退出 0。运行时为 AE2 19.2.18、AE2LT 2.1.1、Thunderbolt 2.0.2。
- `build/verification/alpha9-final-old.log`：同一生产类在 AE2 19.2.17、AE2LT 2.1.0、Thunderbolt 2.0.0 下 264 项必需 GameTest 通过，退出 0。两组均为 Minecraft 1.21.1 / NeoForge 21.1.255，并启用 Mekanism、Mystical Agriculture、Applied Flux。
- 路由 RED 先复现五项失败；放置朝向 RED 先复现一项失败。新增覆盖默认全关、水平迁移、竖直旧布局、正确输入口、中心分流及能量守恒、无输出、多个输入认领、闭环和路径阻挡。
- 框架入口 RED 先复现四项缺少入口的失败；最终覆盖七种激光结构×六个朝向、七格模拟室远角、普通手持物、潜行与工具、不成型、拆除/替换、重复归属、跨世界和卸载。菜单按点击框架距离及当前宿主身份复查。
- 投影几何原先在独立 Minecraft 类路径运行五项单元检查；项目普通 JUnit 不含 Minecraft，已将这些检查迁入真实 GameTests，另加模拟室 3～7×四朝向的字面材料数、模板/独立验证器一致性、不加载区块与不修改世界，以及选择尺寸的实际菜单关闭重开、保存加载和无效操作，共九项投影 GameTests。
- 独立复查发现旧 `PORT` 被误裁开极点，已修正。原始网格下极封闭断言先失败、最终通过；实际控制器和接口按其真实位置裁孔。文档的上游费用错误描述同步修正。见 `docs/reviews/2026-10-07-optical-projection.md`。
- 原生 Blockbench 绘制图集新 52–53 图块和独立 64 帧光束 PNG。旧 0～51 图块逐像素相同；模拟室及坍缩球体资源未改。首尾 RGB 平均差 5.815，邻帧平均 5.866、最大 7.093，循环边界没有异常跳变；帧间插值平滑时间，空间仍为最近邻像素。
- `verify-laser-resources.py`、`verify-multiblock-resources.py` 与 `verify-release.py --tag v0.2.0-alpha.9` 通过。原生工程内嵌 PNG 与运行贴图相同，偏折壳体和 18 个水晶面可独立编辑；独立 JAR 不包含前置二进制或测试数据包。

窗口化原生客户端为 854×480，两轮均使用新版运行时及三个可选模组。在真实界面确认四面全关，设置北面输入/东面输出后显示 100k FE，光从入射口进入中央水晶再由输出口发出；三个格宽的光柱与水平口匹配。F3 确认目标为 `laser_frame` 后右键打开运行界面。

施工投影正确显示粉色框架和青色玻璃，正确部件与障碍实时更新。七格模拟室投影有完整顶面、四面玻璃及留空底部内部；关闭投影页面后重开仍显示七格，实际自动放置 192 个部件，界面自动识别 49 个水晶槽，投影在成型后清除。F3 确认七格模拟室远角 `simulation_frame[formed=true]`，在距离控制器超过八格的位置右键仍能保持控制页面。
