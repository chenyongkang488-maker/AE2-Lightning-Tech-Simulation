## 返还边界

发送失败且原网络同时拒收的余量持久保存在新接口的私有缓冲。AE2 当前公开 API 不提供持久网络／存储单元 UUID，有线锚点经过区块重建或冷重启后不能证明仍是原网络时，余量继续持久保留，避免存入不同网络。公开频率身份可恢复；原有线锚点仍加载时可恢复返还。正常供货不受此边界影响。详情见 [输出接口 API](../output-interface-api.md)。
