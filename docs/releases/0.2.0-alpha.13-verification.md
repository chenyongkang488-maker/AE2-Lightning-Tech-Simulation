# 0.2.0-alpha.13 本地开发验收

2026-10-07，闪电科技：模拟 / Lightning Tech: Simulation，基线 `d87540e`。

本轮完成工作站四项视觉反馈：修复整体发黑；四条稳定透明粉色光束汇聚到下方合成区中央；缩小黄色扳手；成型框架使用浅灰像素面板、深色窄包边、横向散热栅格和少量固定件。保留连续玻璃、完整遮光顶底、四个真实过载水晶簇、后侧收光环和原结构材料。

发黑根因：Minecraft 的 BlockEntityRenderDispatcher 在控制器坐标取光照；此前工作站将该值用于整个七方块模型。底部控制器被框架遮蔽时，实际晒到太阳的外壳也继承低光照。现在各合并表面按中心与四角的实际世界位置采样，局部坐标转换覆盖四个控制器朝向，保留真实天空光/方块光通道，并仅在当前渲染帧缓存已加载位置。未给普通面板强制满亮，也未改变世界光源或服务器逻辑。

四束光从前置原生 NORTH 晶簇的可见尖端出发，终点在中央置物格表面之上。使用既有固定透明 beacon 渲染通道，原生 COLOR_WRITE 保留深度测试但不写深度；双向四边形兼容该通道的面剔除。独立工作站图集的白色像素经顶点染色产生透明粉色，不再滚动能量纹理。光束不会抹掉后方物品、晶簇或台面的像素。独立图集保留原激光玻璃的透明 tile 4，不改变其它仪器共享贴图；扳手透明图的可见区域从 14 像素缩为居中的 10 像素。
