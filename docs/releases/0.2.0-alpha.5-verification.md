# 0.2.0-alpha.5 compatibility verification

Verified locally on 2026-10-06 with Java 21.0.12 and Minecraft 1.21.1. The
development checkout started from `938cdbe` and selectively ported the stable
branch compatibility changes in `0cafe7e` / `f32f146`, preserving all development
features, registry IDs, serialized formats and artwork.

## Automated results

All 64 JUnit tests passed with zero failures/errors. Eight new tests parse the
actual processed NeoForge TOML with NightConfig and Maven version ranges. They
cover current/old dependency admission, later minor/patch policy, lower/upper
bounds, mandatory dependencies and the stable `overload_sim` identity.

## Native client acceptance

The current stack with NeoForge 21.1.255 and the optional test mods loaded the
existing isolated developer world. Computer Use verified:

- The existing particle constrainer and original simulation chamber render in
  the developer world.
- Holding the coil and pressing G opens the shared native weapon tab with the
  coil icon, modules and normal powered state.
- Scrolling reveals all seven coil settings, including the last wrench-purpose row.
- Enabling wrench mode and changing the purpose from general wrench to item
  mode updates the server-backed screen.
- Holding the native railgun changes the same tab's icon/name and restores its
  original settings and scrolling through execution mode.

Screenshots: [coil](../screenshots/coil-upstream-2.1.1.png) and
[railgun](../screenshots/railgun-upstream-2.1.1.png). The client saved the developer
world and exited normally; Gradle exit 0 (`upstream-compat-client.log`). No user
world was used for acceptance. No fatal Mixin/application error occurred.

Upstream optional-integration, sprite/recipe warnings remain in the development
logs. The simulation manufacturing/production tests pass. Independent read-only
code review found no actionable critical, important or minor defects.

## Artifacts and rollback

`python scripts/verify-release.py --tag v0.2.0-alpha.5` passed: metadata,
runtime resources and licenses match the source, and neither dependencies nor
test-only datapacks are bundled. Every packaged `.class` is byte-identical to
the classes used by the final native 21.1.255 client after the 21.1.252 build.

The existing Windows checkout had non-canonical CRLF copies of some tracked
text files. Both development and primary checkouts were refreshed to the
repository's existing LF policy, with every normalized file checked against
its Git blob. Resources and source archives were forcibly repackaged
(`upstream-compat-canonical-packaging.log`); no content or artwork changed.
The final base regression passed all 64 JUnit and 221 required GameTests in 37
seconds (`upstream-compat-canonical-final-green.log`).
