# JEI 多方块结构页

从对应控制器的JEI用途（U）进入“多方块结构”；也按R建立了控制器索引。保留原有制造／加工页面。

范围固定为发射器、约束／强化／爆发／偏折／聚焦矩阵、粒子约束器与强能工作站。模拟室明确不加入；单方块坍缩核心不作为多方块列出。本轮只提供JEI集成，没有新增EMI、GT或LDLib必需依赖。

## 交互

- 左键拖动：旋转；滚轮：缩放；右键或“复位”：恢复视角和全部层。
- 左右按钮：循环查看单层；中间层按钮：恢复全部层。
- 四种环矩阵的“摆放”按钮：切换竖立／平躺，材料总量不变。
- 悬停三维方块：名称、相对控制器坐标、该位置允许的可选替换。
- 悬停“可选项／说明”：完整数量的含义、过载接口／额外光口限制。
- 右侧物品图标沿用JEI的配方与用途查询。

## 默认完整材料

数量包含一个控制器，不包括空气。按层查看不改变右侧完整结构总量。

| 设备 | 默认材料 | 总方块数 |
| --- | --- | --- |
| 高能激光发射器 | 控制器1、框架36、激光源水晶1、光口1 | 39 |
| 约束矩阵 | 控制器1、框架15 | 16 |
| 强化矩阵 | 控制器1、框架15 | 16 |
| 爆发矩阵 | 控制器1、框架15 | 16 |
| 偏折矩阵（六口新版） | 控制器1、框架91、光口6 | 98 |
| 聚焦矩阵 | 控制器1、框架15 | 16 |
| 粒子约束器（带底座） | 控制器1、框架138、玻璃56、光口1 | 196 |
| 强能工作站 | 控制器1、框架141、玻璃75、光口1 | 218 |

合法上游框架可用最多一个过载接口替换；它不属于默认必需材料。粒子约束器球壳的其它水平面中心可换成额外光口，每增加一个光口少用一个框架。强能工作站不提供不受其判定支持的接口替换。

## 实现与验证入口

`StructurePreviewCatalog`直接使用激光施工几何（接收器带底座、新偏折shape2）和工作站模板。模板、默认材料与可选位置独立于JEI和客户端世界，GameTest将预览与实际施工计划逐格比较，并验证八种结构真正成型。预览绘制普通方块模型，不创建运行中的方块实体，也不触发产能、费用、光路或世界修改。

每个JEI布局创建自己的相机、层号、拖动状态。JEI的模拟点击不执行翻层／摆放切换，只有匹配的确认释放执行一次；拖动后在其它控件上松开不会触发该控件。渲染范围裁剪、变换栈和缓冲刷新在局部完成。

开发机如需加载JEI运行集成，使用`gradlew.bat runClient -PjeiTests`；它仅为显式测试增加runtime依赖，普通发行仍为可选JEI。实际启动桌面客户端和鼠标键盘操作必须先取得用户许可。
