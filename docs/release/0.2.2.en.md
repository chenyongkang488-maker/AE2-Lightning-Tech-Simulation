# Lightning Tech: Simulation 0.2.2

Minecraft 1.21.1 · NeoForge 21.1.252 or later in the 21.1 series · Java 21.

- Deflectors support six independently configured ports. Rebuild an existing deflector to use the new template. Constraint, Enhancement, Burst, and Focus matrices can lie flat for vertical beams.
- Controller JEI pages show structure previews and material counts. The upstream JEI preview also fits smaller windows and supports selecting blocks and scrolling through their details.
- The Primordial Module produces natural ore blocks in the multiblock chamber and is mutually exclusive with the Smelting Module. Both simulation chambers support Mekanism fluorite and sulfur dust.
- The Laser Source Crystal accepts any of the four grades of budding overload crystal.
- Added AE2 Lightning Tech 2.1.2-beta4 collector, workbench, and lightning API support. See the [compatibility guide](../upstream-api-compatibility.md) for tested dependency combinations.

Bind fluorite with 24 Mekanism fluorite storage blocks. Bind sulfur with 24 blocks tagged `c:ores/sulfur`; stone, deepslate, and other tagged variants can be mixed. Mekanism itself provides no sulfur ore. AllTheOres is one supported ore provider. Laser resonance processing and its three crystal tiers are scheduled for a later release.

Back up your save before updating from 0.2.1 and use a matching dependency stack. Keep the corresponding alpha build for any alpha test save containing the resonance chamber, its input ports, or its tiered crystals.
