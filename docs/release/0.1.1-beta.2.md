# 闪电科技：模拟 0.1.1-beta.2

适用于 **Minecraft 1.21.1 / NeoForge / Java 21**。这是基于已发布 beta.1 的前置兼容修复版，保留模拟水晶、单方块/多方块模拟室和过载雷鸣线圈的已有玩法。

## 更新内容

- **兼容 CurseForge 当前前置**：支持 AE2 Lightning Tech 2.1.1 与 Thunderbolt Core 2.0.2，同时保留 Reborn 2.1.0 / 2.0.0 支持。
- **修复线圈设备状态错误**：适配新版闪电科技增加的状态字段，解决打开/同步线圈设备界面时的 `NoSuchMethodError`。
- **修复客户端界面注入错误**：兼容新版设备界面的滚动实现，七项线圈设置均可正常滚动显示，原生轨道炮继续使用其自身设置。
- **统一名称**：模组列表、创造栏、游戏内指南和文档统一叫“闪电科技：模拟” / “Lightning Tech: Simulation”。新文件名使用 `lightning-tech-simulation`。
- **补齐兼容说明与回归验证**：明确必需前置、安装步骤及已验证版本组合。

内部模组 ID、物品/方块注册 ID、配方和存档数据保持兼容。本次不包含 0.2.0 开发功能。

## 前置与安装

| 必需组件 | 推荐安装版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| Java | 21 |
| NeoForge | 21.1.255；声明支持不低于 21.1.252 的 21.1.x |
| Applied Energistics 2 | 19.2.17 |
| GuideME | 21.1.19 |
| AE2 Lightning Tech | [2.1.1](https://www.curseforge.com/minecraft/mc-mods/ae2-lightning-tech/files/9024605) |
| Thunderbolt Core | [2.0.2](https://www.curseforge.com/minecraft/mc-mods/thunderbolt-core/files/9055479) |

也可保留原 Reborn AE2LT 2.1.0 / Thunderbolt 2.0.0。Reborn 已迁回上述主项目，内部 ID 相同，每种前置只保留一份；早期闪电科技 2.0.x 不受支持。

客户端和服务器都安装普通 **`lightning-tech-simulation-0.1.1-beta.2.jar`**，移走旧版附属 JAR，包括旧文件名的 beta.2。只装 AE2、GuideME 与本附属模组仍会缺少前置，必须另行安装闪电科技和 Thunderbolt。源码 JAR / ZIP 用于开发，不能放入 mods。

Mekanism 为可选兼容；神秘农业/Cucumber 为可选作物兼容，均不是强制前置。

## 验证

- 24 项单元测试通过。
- Reborn 2.1.0 / 2.0.0 + NeoForge 21.1.252：153 项功能测试通过。
- CurseForge 2.1.1 / 2.0.2 + NeoForge 21.1.252 和 21.1.255：每套 153 项功能测试通过。
- 新旧前置客户端均实测进入世界、按 G 打开线圈设备界面、滚动显示全部七项设置及正常退出。

仍为 Beta；上述结果对应明确的测试组合，不表示所有第三方整合包或未来前置版本均已验证。

## English changelog

**Lightning Tech: Simulation 0.1.1-beta.2** is a compatibility update for Minecraft 1.21.1 / NeoForge / Java 21.

- Support AE2 Lightning Tech 2.1.1 and Thunderbolt Core 2.0.2 while retaining Reborn 2.1.0 / 2.0.0 support.
- Adapt the coil device-status model to the added upstream field and fix the `NoSuchMethodError`.
- Fix the client scrolling Mixin for the new device hub; all seven coil settings remain accessible.
- Unify the public name and use `lightning-tech-simulation` for distributable filenames. Internal registry IDs and existing-save data remain compatible.
- Preserve existing gameplay and recipes; this release contains no 0.2.0 development features.

Required: AE2 19.2.17, GuideME 21.1.19, AE2LT 2.1.1 and Thunderbolt 2.0.2 (or the original Reborn pair above). Install the ordinary JAR on both client and server and remove the previous addon JAR. Do not install two dependencies with the same mod ID. Mekanism and Mystical Agriculture/Cucumber support are optional.

Verified locally: 24 unit tests, 153 GameTests per listed runtime profile, and the coil device hub on both old and current client dependencies. This remains a Beta release. Code/original artwork: MIT; adapted crystal/module artwork: CC BY-NC-SA 3.0, with attribution included in the JAR and source.
