# 闪电科技：模拟 0.2.1 更新公告

本次是 0.2 系列的首次公开更新。此前开发的 0.2.0 未单独发布，整套激光产线与 0.2.1 的过载输出接口一起收录在这一版中。已有模拟水晶、模拟室和过载雷鸣线圈继续保留。

## 整套激光与粒子产线

新增高能激光发射器，以及约束、强化、爆发、偏折和聚焦矩阵。通过不同矩阵调整激光强度与光路，偏折矩阵可汇合多个输入，再按启用的输出面分流。

聚焦后的激光进入坍缩核心，产生的粒子继续沿光路送往粒子约束器。约束器使用对应耗材处理粒子并输出 FE，支持超限水晶及多种原版、闪电科技和可选模组材料。整条产线按实际接收与消耗结算，保存未用完的资源余量。

设备提供生存制造配方、运行状态和 G 键指南。多方块可自动搭建并显示施工投影，材料优先从背包取用，再从已连接的 AE 网络补齐。

## 强能工作站与超限水晶

强能工作站是 7×7×7 多方块，使用通用激光框架、玻璃和光口。默认在单束激光强度严格超过 1GFE 时工作，继承过载处理工厂配方，以激光替代原 FE/闪电费用，仅消耗配方材料；默认每两 tick 最多处理 1024 次。

工作站支持大容量物品缓存、真实流体槽和容器交互。相邻容器自动弹出与 AE 网络产物导出可分别开启，并补齐 JEI 的工作站配方页面。

新增淡蓝色超限水晶：在强能工作站中，256 个过载水晶可制成 4 个超限水晶。装有闪电坍缩矩阵的特斯拉线圈可使用超限水晶生产极高压；它也可用作粒子约束器耗材。相关门槛与用法可在 G 指南和 JEI 中查看。

## 过载输出接口

新增独立的过载输出接口，提供 36 个虚拟样板槽，两页各 18 组。普通模式向相邻容器供货；无线模式按源槽位向绑定目标的指定面供货。数量设置代表每槽每轮共享的输出预算，持续供应直到网络缺货或目标拒收。接口没有回收和被动输入功能。

连接工具操作：右键源接口 → Shift＋滚轮选择槽位 → 右键目标面。再次右键同一目标面可取消当前槽连接；Ctrl 批量绑定只添加缺失连接。目标管理页可以删除单条连接或清空某槽，36 个源槽各有固定颜色的连接光线。

同槽支持多个目标，更换样板后连接立即跟随新的供货内容，空槽暂停资源输出。安装感应卡后向所有有效连接供 FE，重复目标面只供能一次。默认同维度范围 128 格，允许跨维度；不会强制加载目标区块。

## 配置、交互与兼容修复

主菜单 → 模组 → 闪电科技：模拟 → 配置，可调整机器运行数值、容量、范围和约束器爆炸开关。修改容量上限会保留已有库存；新的机器参数按配置说明生效，多人游戏以服务器配置为准。

本版修复 Sodium 环境自动搭建后的外壳光照查询崩溃，优化外壳光照缓存和视野裁剪，并调整施工投影绘制。补齐升级卡右键插入与 JEI 页面入口，适配新版闪电科技移动后的客户端按钮、快捷键和连接光线渲染路径。

## 前置与升级

适用于 **Minecraft 1.21.1 / NeoForge / Java 21**。推荐配套：

| 组件 | 推荐版本 |
| --- | --- |
| NeoForge | 21.1.255（本模组最低 21.1.252，限 21.1.x） |
| Applied Energistics 2 | 19.2.18 |
| AE2 Lightning Tech | 2.1.2-beta2 |
| Thunderbolt Core | 2.0.3-beta2 |
| GuideME | 21.1.19 |

AE2、AE2 Lightning Tech、Thunderbolt Core 和 GuideME 是必需前置。AE2 Lightning Tech 与 Thunderbolt 是独立项目，不随本模组分发。旧 Reborn 和新主项目使用相同 ID，每种前置只安装一份。

Applied Flux（应用通量）及其前置为可选组件；通过 ME 网络存取 FE 时，需要应用通量的 FE 存储单元，AE 能源单元只承担网络运行开销。JEI 可选，用于配方展示；Mekanism 和神秘农业等为可选兼容内容。封包样板供应器不是本模组的必需前置。

升级前备份存档，移走旧附属 JAR，再安装 `lightning-tech-simulation-0.2.1.jar`。客户端与服务器同步更新；sources JAR 和源码 ZIP 用于开发，不放入 mods。内部 `overload_sim` ID、资源命名空间和原有注册 ID 保留。

声明的依赖范围及构建命令见 README。后续前置更新仍可能改变 API；推荐组合与本次实际验证结果见 `docs/releases/0.2.1-verification.md`。
