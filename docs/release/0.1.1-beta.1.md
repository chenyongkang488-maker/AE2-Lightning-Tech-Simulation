# AE2 Lightning Tech: Simulation 0.1.1-beta.1

Minecraft **1.21.1** · NeoForge **21.1.252–21.1.x** · Java **21** · **Beta**

This candidate prepares the existing 0.1b gameplay for open-source release.
Author metadata is qiqi. Binary and source JARs now include the MIT license,
artwork license scope and upstream attribution. Builds use a checksum-pinned
Gradle wrapper with no machine-specific build paths. Bilingual docs, issue
templates and Windows/Linux build CI are included.

玩法沿用 0.1b，本次整理许可、构建、介绍和反馈流程；物品、方块、配方、
存档 ID 保持不变。原 0.1b 文件及标签保留。

Required mods: AE2 **19.2.17**, AE2 Lightning Tech **Reborn 2.1.0**,
Thunderbolt Core **Reborn 2.0.0**, GuideME **21.1.19**.
Install the ordinary JAR on client and server; remove older addon JARs.
Sources JAR / source ZIP are for developers.

Code and original artwork: MIT. Adapted crystal/module art: CC BY-NC-SA 3.0.
See the bundled license scope and attribution.

Validation results for this candidate are recorded in docs/releases/0.1.1-beta.1-verification.md.
The GitHub workflow is prepared locally; its hosted run must be checked after the
repository is created. This release does not add a new manual game-session check;
long-term worlds, multiplayer and additional third-party integrations remain beta test scope.
