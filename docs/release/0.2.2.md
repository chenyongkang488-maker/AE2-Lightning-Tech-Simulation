# 闪电科技：模拟 0.2.2

Minecraft 1.21.1 · NeoForge 21.1.252 或更高的 21.1.x · Java 21。

- 偏折矩阵新增上下光口，完整六口需要按新模板重建。现有偏折矩阵可继续使用原布局。约束、强化、爆发和聚焦矩阵可平躺安装，让激光垂直通过。
- 支持从对应控制器的 JEI 页面查看多方块结构和材料。改进新版闪电科技结构预览的小窗口取景、布局、方块选中和详情滚动。
- 多方块模拟室新增原初模块，可以直接生产自然矿石，与熔炼模块互斥。原有普通模拟室和多方块模拟室均支持通用机械氟石与硫粉。
- 激光源水晶配方接受四档过载水晶母岩中的任何一档。
- 适配 AE2 Lightning Tech 2.1.2-beta4 的集雷器、工作台和闪电 API。测试前置组合见[兼容说明](../upstream-api-compatibility.md)。

氟石使用 24 个通用机械氟石块绑定。硫使用 24 个带 `c:ores/sulfur` 标签的硫原矿绑定，可混用普通和深层等变体。通用机械自身不提供硫矿，支持 AllTheOres 等提供标签的模组。激光共振加工室及三阶共振晶体留待后续版本。

从 0.2.1 升级前请备份存档，使用匹配的前置组合。已在 alpha 测试存档中放置共振加工室、专用进料光口或保存三阶共振晶体时，请继续使用对应 alpha 包。
