# 强能工作站与真实激光光照

目标：新增外尺寸 7×7×7 强能工作站，保留粉白像素风，以激光替代原配方 FE/闪电费用；坍缩核心改为无需网络的被动光学器件。执行延续用户先拟定方案后直接制作的开发偏好。

## 约定

- Minecraft 1.21.1 / NeoForge；编译基于 AE2 19.2.17、AE2LT 2.1.0、Thunderbolt 2.0.0，验证新旧前置。
- 名称闪电科技：模拟 / Lightning Tech: Simulation，保留 overload_sim 和 dev.overloadsim。
- 工作站外尺寸固定 7；顶底和接收壁封闭，另三面玻璃；控制器在正面底边中央，接收器在背面中央。四颗内部水晶汇聚到下方中央置物台。
- 9 个材料格、9 个产物格，均使用数量独立于 count-one 物品原型的存储，每格 1,000,000。最多 1024 并行，两个连续有效 tick 完成一次；强度必须严格大于 1,000,000,000 FE。材料在完成时原子结算。
- 继承运行时最终配方对象，包含 tag、组件、液体及整合包修改。独立类型 overload_sim:high_energy_workstation 留给数据包作者。费用由激光替代，只消耗材料，保持原加工配方的消耗/结果语义。
- 用户已澄清继承的是过载处理工厂加工配方，包含运行时借用配方；装备模块装配不属于本轮。
- 所有资源交互位于控制器：物品/液体 capability、手动取放和 shift 快捷操作、可配置六面、弹出和可选 AE 产物导出。新接口默认关闭；不导出材料格。
- 保留自动搭建、客户端施工投影、成型框架入口；控制器拆除携带库存，卸载不强制加载其它区块。
- 核心只显示收到的能量、累计余量及阈值；移除工具栏、开关、背包格和网络状态。拒绝实体线缆/频率绑定/FE capability，旧数据资源不丢失，旧关闭状态恢复为可接收。
- 激光和发射面用真正 Minecraft 光源：透明无碰撞的有归属光照代理，光照 15，数量及维护工作有界。只替换空气；多光束共享，停机/拆除/重载后回收，不破坏方块或液体。

## Implementation Plan

并行分工：后端独立目录 workstation（配方/存储/结构）；核心和光照独立改动 laser；主代理菜单、资产、渲染、注册和整体验证。共享接口使用上述名称和数值；同一个 Gradle 工作树同一时刻仅一个执行者。

- [x] 核心隔离与光照：先复现 CORE 频率绑定/FE 接口仍可用、光照仍为 0；实现只读页面及有界共享光源；验证卸载、停机和方块保护。
- [x] 配方与存储：先固定百万格上限、重叠 Ingredient 分配、1024 并行和输出满不扣料；高数量匹配使用最大流，避免按物品个数搜索。运行时重载在两个 tick 间取消失效任务。
- [x] 多方块：模板明确 343 单元，218 个外壳块；其中控制器 1、接收器 1、玻璃 75、框架 141。验证四朝向、归属冲突、远框架入口、自动搭建材料与形成一致，不加载区块。
- [x] 菜单/资产/渲染：合法原型同步数量，手动取放/shift 无复制；两组 3×3 格，精确数量 tooltip、强度和并行显示。顶底白瓷面板、立柱粉色光槽，大型收光盘、四水晶和置物台保持像素几何。无共面贴片。
- [x] 整体验证：JUnit、全部 GameTests、新旧前置运行时、资源完整性；窗口化客户端验证核心简化、工作站形成、收光与真实光照、输入输出和 1024 并行。
- [ ] 本地集成、alpha.10 构建、测试实例仅替换附属 JAR、旧版备份、记录校验与截图。不上传或发布远程版本。

复查重点：百万数量不能进入普通持久化/网络堆叠 codec；材料不能被自动化当产物抽走；删除/改写配方不能继续旧合成；强度等于阈值必须不工作；共享光源不能相互熄灭或覆盖玩家方块。
