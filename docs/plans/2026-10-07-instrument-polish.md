# 仪器外观与过载网络修正 · alpha.8

目标：保留像素方块风格、现有存档 ID、光路能量和费用规则，落实用户截图中的八项问题。测试客户端保持窗口模式。

1. 反应堆及矩阵相交盒体生成并集，只保留外表面；发光面只绘制一次。原生 Blockbench 图集分别保留装甲、导光、屏幕和玻璃图层。
2. 按最新用户反馈，激光整体恢复 alpha.7 的几何、模拟室流纹、透明外光层和亮芯，撤销圆弧封口及深粉色往复版本。
3. 外环恢复 alpha.7 的粉色约束符文和青色聚焦符文；保留装甲并集去重和四个原生绘制图层。
4. 偏折矩阵成型后合并为带导光肋的像素球壳，保留六个真实光学端口及控制器、过载接口开口。
5. 八类仪器与模拟室支持原生过载频率卡、界面和 AE 内存卡。区块完整卸载后保留离线设备记录，永久拆块注销；拆结构接口只释放自己拥有且仍存在的连接。
6. 去除模拟室八角方形饰片与额外梁/顶通风装饰，保留连续粉白边框。
7. 模拟室自动搭建留空底部内部升级位，已有合法升级或框架原样保留，底边和顶部仍需完整。
8. 粒子约束器底座改为连续粉白陶瓷面板，控制器保留实际服务器方块与交互，客户端屏幕嵌入整体底座。

验证采用几何单元测试、真实前置网络及结构 GameTest、资源/许可/构件校验，以及窗口 Minecraft 的原生 F2 截图。网络卸载回归执行 NeoForge 的 `LevelChunk.clearAllBlockEntities()` 完整回调序列，并按真实存档加载流程创建新宿主，验证无线恢复与实际拆块注销。新旧前置组合使用同一组编译类。最终仅替换现有测试实例内的附属 JAR，保留旧版备份及其它模组、配置；不发布远程版本。
