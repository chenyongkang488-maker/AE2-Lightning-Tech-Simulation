# 过载输出接口

两页共36个虚拟样板槽，不消耗设置样板的资源。对应库存槽展示已连接 ME 网络中的资源。接口只向外输出，不能存入资源，也不会回收目标物品。

普通模式向相邻容器供货；无线模式向绑定目标的指定面供货，两种模式互斥。有货且目标能接收便持续发送。配置数量限制同一源槽每轮对所有目标的总发送量，不是目标保有量；无限模式取消槽位数量限制，目标轮流获得供货机会。

切换无线模式，手持无线过载连接工具右键本接口。按住 Shift 滚轮循环选择槽1～36，再右键目标的输入面。Ctrl＋右键可批量连接同类相邻目标。重复绑定不会删除连接；在目标管理页删除单个连接或清空该槽连接。右键空气清除工具选择。

更换样板会更换该槽全部目标的供货资源；清空样板暂停资源供货但保留连接，空槽也能提前绑定。安装应用通量感应卡后，所有绑定目标面均可获得 FE，包括空样板槽的连接；同一目标面只计算一次。没有应用通量或感应卡时不输送 FE。

删除连接需要手持连接工具。将工具放在副手，用空主手打开接口，再进入目标管理页即可操作删除和清空。

手持连接工具时显示同维度连接光线与目标面高亮，36个槽位各用固定颜色。选中接口后仅显示该接口，瞄准新目标面可预览绑定；同面多槽的端点分开显示。空槽保留光线，跨维度连接不在当前维度绘制。

最多1024条源槽连接。同维度默认128格，默认允许跨维度；目标区块未加载时暂停，不强制加载。正常供货最快每1 tick一次，空闲时自适应延长检查，NORMAL最多80 tick，FAST最多20 tick；FAST基础网络运行耗能为1.5倍。升级支持合成卡、模糊卡、感应卡，不接受加速卡；定向供货始终精确匹配资源。

制造：闪电装配室投入4 ME接口、256福鲁伊克斯珍珠、2过载机器框架、1输出总线、1过载奇点，消耗1,000,000 FE及16极高压，得到1个接口。

主菜单模组配置中的 `overload_sim-output.toml` 提供 `wirelessRange`（0为无限距离）与 `allowCrossDimension`。多人以服务端配置为准。Java连接接口及可取消输出事件详见源码仓库 `docs/output-interface-api.md`。
