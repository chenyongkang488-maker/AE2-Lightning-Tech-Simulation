# 强能工作站

工作站加工当前加载的**过载处理工厂配方**，整合包修改、删除配方后会同步生效。激光替代原配方的 FE 与闪电费用，工作站只消耗配方材料，包括流体。

内置专属配方：**256 个过载水晶合成 4 个超限水晶**。淡蓝色超限水晶可配合闪电坍缩矩阵在特斯拉线圈中生产极高压，也可作为约束器耗材；详见[超限水晶](transcendent-crystal.md)。

外尺寸为 **7×7×7**，需要 1 个强能工作站控制器、1 个激光光口、141 个激光框架和 75 个激光通光玻璃。控制器放在正面底部中央，屏幕朝外；光口放在对面墙中央，比控制器高三格。顶面、底面和背墙封闭，其余三面各有 5×5 玻璃窗。内部 5³ 区域留空。成型后外壳合并为浅灰像素面板、深色包边、横向散热栅格和连续玻璃窗，黄色小扳手标识控制器；四个过载水晶簇贴住收光面内壁，运行时发射四条透明粉色光束，汇聚到下方置物台中央。空腔阻止所有类别的生物自然生成，包括蝙蝠。

光口需要收到**单束强度严格大于 1,000,000,000 FE**的激光；多束弱光不会相加。材料和输出空间充足时，两个有效 tick 完成一轮，每轮最多执行 1024 次配方。断光或拆除结构会取消未完成进度，不扣本轮材料。

控制器有九个输入格、九个输出格，每格容量 1,000,000。悬停可查看精确数量；左键移动普通堆叠，右键移动一个物品，Shift 点击在背包与机器间快速转移。自动化只向输入格放入、只从输出格抽取。

物品区两侧的竖直流体槽按真实流体材质和液位显示，并带刻度；每槽容量为 1,024,000,000 mB，保留流体组件，悬停可查看精确余量。拿装有流体的容器点击输入槽可灌入，拿空容器点击任一流体槽可取出。输出槽只允许取出。

控制器任意面均可输入材料和抽取产物；输入格和输入流体不能被管道抽走，输出格和输出流体不能被灌入。工具栏提供“自动弹出到相邻容器”和“自动导出到 AE 网络”两个独立开关，默认关闭。其它外壳仅提供菜单入口，不提供物品、流体接口。成型后右键所属框架即可打开控制页面。接收光束不要求聚焦，单束强度仍须严格超过 1GFE。

自动搭建先取背包材料，再从已连接的 AE 网络补齐；创造模式无需材料。其下方的虚拟投影可预览缺失方块，不改变世界。创造管理员可在已加载的空区域使用 `/overload_sim workstation demo`，生成预充有限资源的激光演示链与工作站。

工作站专用施工物品只保留控制器。旧结构完整成型时，原专用框架、玻璃和接收器会转成对应激光部件；单独拆下旧部件也会掉落对应激光物品。背包里的旧部件可在合成栏一比一转换，不需要额外材料。迁移保留控制器库存和流体。

作者可通过 `overload_sim:high_energy_workstation` 类型添加专属配方，格式沿用过载处理工厂。Java 配方来源 API 见仓库 `docs/workstation-api.md`；自定义来源应返回最终可执行配方，并保留材料判断及物品组件。
