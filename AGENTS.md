# Project naming

- The public Chinese name is **闪电科技：模拟** (exact punctuation, no AE2 prefix).
- The public English name is **Lightning Tech: Simulation**.
- Use `lightning-tech-simulation` for new distributable JAR names and build artifacts.
- Use these names in mod metadata, creative tabs, guides, documentation, covers and release text. Do not call the project Overload Sim or Overload Simulation.
- Preserve the internal mod ID/resource namespace `overload_sim`, Java package `dev.overloadsim`, registry IDs and guide resource paths for existing-save compatibility. These technical identifiers are not the public project name.
- Preserve historical release filenames, verification hashes and existing GitHub repository URLs; do not rename remote projects without a separate request.
